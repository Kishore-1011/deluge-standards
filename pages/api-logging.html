Engineering Manual — Section 4

API Logging & Observability Standards

Official corporate engineering standards governing mandatory API audit logging, transaction tracing, schema attributes, and diagnostic logging across all Zoho integrations.

Mandatory API Audit Policy

Every integration function connecting to CRM, Books, Inventory, Creator, or third-party REST APIs must maintain a structured audit log. Unlogged API operations violate security compliance guidelines.

4.1 Mandatory API Audit Log Maintenance

Rule

Every API integration connecting to CRM, Books, Inventory, Creator, or third-party REST APIs must log every incoming and outgoing execution event for both success and failure paths.

Why

Audit logging ensures operational visibility into inter-system transactions, allowing immediate root-cause analysis and incident resolution.

Example

Good Example
deluge 
auditMap = Map();
auditMap.put("Function_Name", "syncCustomerInvoiceToBooks");
auditMap.put("API_Name", "ZohoBooks.CreateInvoice");
auditMap.put("Status", "SUCCESS");
auditMap.put("Executed_User", zoho.loginuser);
zoho.creator.createRecord("audit_app", "all_form", "API_Audit_Log", auditMap, Map(), "zcreator");
Bad Example
deluge 
// Unlogged API invocation
booksAPIResponse = invokeurl [ url:"https://books.zoho.com/api/v3/invoices", type:POST, ... ];

Checklist

  • All API calls logged
  • Captures status and user context
  • Handles success and failure branches

4.2 Log Schema Attributes & Context Tracking

Rule

Every API audit log entry must record standard attributes: Function Name, API Name, Request, Response, Status, Execution Time, User, Date Time, and Error Message.

Why

Uniform log attributes enable automated log indexing and fast search filtering when investigating production defects.

Example

Good Example
deluge 
startTime = zoho.currenttime.toLong();
crmAPIResponse = invokeurl [ ... ];
executionTimeMs = zoho.currenttime.toLong() - startTime;
info "LOG_AUDIT | Function: syncCustomer | API: ZohoCRM.UpdateContact | Status: SUCCESS | Duration: " + executionTimeMs + "ms";
Bad Example
deluge 
info "API finished: " + response;

Checklist

  • Function and API names captured
  • Execution duration recorded
  • Standard key-value format
